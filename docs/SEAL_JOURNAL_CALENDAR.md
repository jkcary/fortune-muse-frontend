# Reflection before sealing and calendar card overlays

The personal journal panel now appears as the first step of the closing modal, immediately after Seal This Reading is clicked. It is removed from the inline reading layout. The existing reflection, explicit memory checkbox and favorite controls keep their existing save endpoints. Opening, closing or continuing past the reminder makes no writes. Save errors are visible inside the modal and retain the draft. Continue to seal starts the existing seven-second ritual (or goes to the keepsake with reduced motion). Cancelling the reminder does not mark the ritual completed.

The parent reading keeps unsaved reflection text during modal close/reopen. Saving still uses the existing private journal behaviour. Memory remains separate and requires explicit selection; its 500-character bound is unchanged. Guests are invited to sign in and the modal is dismissed before the sign-in route opens. Private readings skip the journal reminder and retain their temporary flow. The post-ritual optional thought editor is still available.

Calendar day markers now include the latest actual primary hexagram for that date, drawn above the day number. The date/glyph share one accessible hit target. Month metadata contains the real bits and number independently of the paginated card list; multiple readings keep their count. Days with no readings have no invented hexagram.

Clicking a date opens a transparent, centred modal above the calendar. Cards no longer expand below it. The modal has a close icon, backdrop dismissal and Escape/Android-back handling. It fetches that day's readings separately, preserves the calendar position and allows previous/next navigation, including further archive pages. It supports empty dates, fetch retries, collection changes and opening the full reading. The same approved public-card renderer excludes private questions, background, journal text and action work. Small screens keep the close control fixed above scrollable contents. Reduced motion disables the modal fade.

No schema migration is needed. The archive response adds `bits` and `number` to each day marker. Collection layout remains unchanged. New controls have all four existing locale variants.

Validation: 136 backend tests pass, including a 30-reading day whose marker uses its latest actual hexagram and whose cards span multiple pages. Browser fixtures cover journal-on-seal, save retry/draft retention, favorite changes, memory opt-in/length validation, skipping without writes, actual glyph ordering, multi-page day cards, close button/backdrop/Escape and 320px layouts. Fixture scripts and screenshots are in ignored `output/playwright/seal-*` and `calendar-popup-*` paths. Web/iOS/Android exports verify packaging; installed native device acceptance remains separate.
