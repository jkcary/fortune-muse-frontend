# 庭院动态光影

Web 庭院在原 SVG 上叠加 Three.js 透明正交场景，首页与游戏页共用。沿用已解锁、已摆放的装饰及实际点亮的灯数，不改变关卡、收藏或保存逻辑。

- 星空各自使用不同周期和相位缓慢明暗变化。
- 灯笼、路灯、月亮及珍珠有柔和的光晕；地面补充椭圆光斑，珍珠水池加入弱反光和扩散涟漪。
- 五株星花使用有厚度、倒角和受光面的五角星，以种植根部为轴，随共同微风错峰轻摆。
- 不载入远程模型或贴图，不增加拖动相机或额外交互。

Three.js 延迟加载。SVG 首先显示，WebGL 初始化失败或 context lost 时保留完整矢量庭院。iOS/Android 原生包继续使用轻量矢量庭院；本次 Three.js 动效只在 Web 启用。

像素比最高 1.5，渲染最高 30 fps。路由失焦、庭院滚出视口、浏览器后台时暂停循环；“减少动态效果”开启时绘制静态帧。卸载时移除观察器、事件监听，释放几何体、材质、纹理和 WebGL context。

场景坐标与原图的 720 × 300 viewBox 对齐，宽窄屏均保留原来的等比居中显示。

验证：前端类型检查；Web / iOS / Android 资源导出；浏览器实测首页及游戏页、390px 窄屏对齐、动画帧变化、减少动态效果后画面静止、滚出视口后停止绘制，以及 WebGL 初始化失败 / context lost 后矢量回退。浏览器截图与验收脚本位于忽略目录 `output/playwright`。
