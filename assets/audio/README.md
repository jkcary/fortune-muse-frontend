# Coin toss

`coin-toss.wav` is an original procedural copper-coin effect for ORACLE ONE, generated by `scripts/make-coin-sound.py`. It uses damped inharmonic resonances, short impacts, three staggered landings and settling bounces. No third-party recording or sample is used.

- 1.18 seconds, 44.1 kHz stereo, 16-bit PCM (208,196 bytes).
- Release rattle begins immediately; landings begin at 710 ms; the final bounce is at 940 ms, followed by a short fade.
- The visual toss lasts 1 second. Playback starts directly from the user's click, once per casting action, including a single cue for completing remaining lines together.
- The page reuses one player and rewinds before replay. Muting, leaving the page or backgrounding stops playback. The local sound preference defaults on and survives reloads.

Run `python scripts/make-coin-sound.py` from the frontend directory to reproduce the asset. NumPy is only needed for asset generation, not at runtime.
